# Насочване на запитвания

Кратък прототип, който чете едно потребителско запитване и го насочва към екип.

Категории:
- Технически проблем
- Достъп или регистрация
- Учебно съдържание
- Друго

Няма интерфейс и няма база данни. В заданието е написано, че не се изисква нито едното, нито другото.

## Подход

Съобщението се класифицира с правила по ключови думи на български. Те покриват примерните клиентски запитвания и продължават да работят, когато няма достъп до Ей Ай модел(AI API).

Ей Ай моделът се вика само когато правилата не разпознаят текста. `mock_model` в `classify.py` стои на мястото на AI API. Ако извикването се провали, резултатът от правилата се връща непроменен.

Обработката минава така:

1. В текста има ключова дума. Категорията е готова и AI API не се вика.
2. Няма ключова дума. Текстът се праща към AI API.
3. AI API не отговори: няма връзка, времето изтича или идва грешка. Категорията остава "Друго".
4. AI API отговори с една от четирите категории. Ползва се неговата категория.
5. AI API отговори, но връща "Друго". Категорията остава "Друго".

Програмата не препраща запитването към екип. Тя само връща категорията. "Друго" значи, че човек трябва да го прочете клиентското запитване.

## Стартиране

От тази папка:

```powershell
python classify.py
python test_classify.py
```

Без аргументи `classify.py` чака на `>`. Напишете запитване и натиснете Enter. Празен ред спира програмата. Може да подадете и едно запитване директно:

```powershell
python classify.py "Видеоурокът по математика не се зарежда."
```

Разпознато запитване изглежда така:

```json
{"ok": true, "category": "technical_problem", "label": "Технически проблем", "method": "rules"}
```

Празен текст, стойност, която не е текст, или текст без думи изглежда така:

```json
{"ok": false, "category": null, "label": null, "error": "Текстът на запитването е празен."}
```

Стига Python 3.9 или по-нов. Няма пакети за инсталиране.

## Интеграция

Платформата вече получава имейли и бележки по телефона като текст. След като този текст е записан, едно извикване на `classify` добавя категорията. Това може да направи работник за поща или малък HTTP край. Функцията не пази състояние, затова повече заявки означават повече работници, а не обща сесия.

Ако външният модел изтече или е спрян, пътят с `except` запазва резултата от правилата. Познатите случаи пак се насочват. Непознатите остават в Друго, за да ги прочете човек.

## Възможни следващи стъпки

1. Връщане на степен на увереност и изпращане на несигурните запитвания към човек, преди да стигнат до екип.
2. Свързване на всяка категория с екипа, който трябва да я получи, така че резултатът да е направление, а не само етикет.
